# TempleTrail India — v2

A multi-page cultural heritage discovery website for exploring Indian temple traditions, regions, festivals, and visitor guidance.

## Features
- Separate routes/pages for Home, Regions, Region details, Temple details, Festivals, and Visit Guide
- Rich Indian heritage visual theme (deep brown, saffron/gold, terracotta, cream, green)
- Responsive desktop/mobile layout
- Temple cards and detailed temple pages
- Region exploration across South, North, West, East, Northeast, and Central India
- Festival cards with video-search links
- Visitor etiquette and cautions
- React + Vite + React Router

## Run locally
1. Install Node.js (LTS).
2. Extract this ZIP.
3. Open a terminal in the project folder.
4. Run:
   ```bash
   npm install
   npm run dev
   ```
5. Open the local URL printed by Vite.

## Build
```bash
npm run build
```

## Deploy free
Push this project to GitHub and import the repository into Vercel. Vercel's framework preset is Vite; build command `npm run build`, output folder `dist`.

## Data note
This is an early demo dataset. Temple schedules, entry rules, festival dates, visitor restrictions, and video links must be checked against official sources before publishing as a factual travel guide. The image URLs are remote illustrative images and may need replacing with licensed/verified images.
